# Solana Hunter AI — نسخه آزمایشی هشداردهنده

این پروژه فقط پیام هشدار تلگرام می‌فرستد و هیچ خریدوفروشی انجام نمی‌دهد.

## راه‌اندازی
1. متغیرهای محیطی `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` را در میزبان تنظیم کنید.
2. برنامه با Python 3.11 و دستور `pip install -r requirements.txt` اجرا می‌شود.
3. دستور اجرا: `python bot.py`

## محدودیت‌های مهم
- داده‌ها از API عمومی DexScreener دریافت می‌شوند؛ دسترسی، نرخ درخواست و شکل پاسخ API ممکن است تغییر کند.
- امتیاز ۰ تا ۱۰۰ فقط یک فیلتر ساده و آزمایشی بر پایه نقدینگی، حجم و تعداد معاملات است؛ مدل هوش مصنوعی، بررسی امنیتی کامل یا پیش‌بینی سود نیست.
- این نسخه بررسی مالکیت قرارداد، امکان مسدودسازی فروش، توزیع هولدرها، کیف‌پول‌های هوشمند یا تشخیص باندل را انجام نمی‌دهد.
- هیچ‌وقت توکن ربات یا اطلاعات محرمانه را در GitHub بارگذاری نکنید. آن‌ها را فقط در بخش متغیرهای محیطی سرویس میزبانی وارد کنید.
- برای اجرای پایدار ممکن است میزبان هزینه دریافت کند.
